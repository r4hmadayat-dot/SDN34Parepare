PANDUAN MEMASANG KEHADIRAN GURU SEBAGAI PWA

A. Bagian yang sudah tersedia
1. index.html          = shell PWA.
2. manifest.webmanifest= identitas, ikon, mode standalone.
3. sw.js               = service worker.
4. config.js           = URL Web App Apps Script.
5. icons/              = ikon 192x192 dan 512x512.
6. Code.gs + Index.html= versi Apps Script yang sudah diseragamkan dengan nama baru.

B. Langkah 1 - Siapkan Web App Apps Script
1. Pastikan Web App Apps Script sudah di-deploy.
2. Gunakan URL /exec.
3. Contoh format:
   https://script.google.com/macros/s/XXXXXXXXXXXX/exec
4. Jangan masukkan PIN/password ke file PWA.

C. Langkah 2 - Isi URL di config.js
Buka config.js.
Ubah:
   appUrl: 'PASTE_URL_WEB_APP_APPS_SCRIPT_DI_SINI'
menjadi URL /exec Anda.
Contoh:
   appUrl: 'https://script.google.com/macros/s/AKfycbxxxxxxxx/exec'
Simpan.

D. Langkah 3 - Buat repository GitHub
1. Masuk ke GitHub.
2. Create new repository.
3. Nama contoh: kehadiran-guru-pwa
4. Upload seluruh isi folder PWA ini.
5. Pastikan index.html, config.js, manifest.webmanifest, sw.js berada di root repository.
6. Folder icons harus berada di root dan berisi icon-192.png dan icon-512.png.

E. Langkah 4 - Aktifkan GitHub Pages
1. Buka repository.
2. Settings.
3. Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /(root).
7. Save.
8. Tunggu deployment selesai.
9. Buka URL GitHub Pages Anda.
   Contoh:
   https://USERNAME.github.io/kehadiran-guru-pwa/

F. Langkah 5 - Uji PWA
1. Buka URL GitHub Pages dari Chrome Android.
2. Pastikan halaman memuat aplikasi utama.
3. Login guru/admin.
4. Uji GPS.
5. Uji upload lampiran.
6. Uji semua menu.
7. Uji print/PDF.

G. Langkah 6 - Instal
Setelah situs memenuhi persyaratan instalasi browser, Chrome dapat menampilkan opsi instalasi.
Gunakan tombol "Pasang Aplikasi" yang tersedia pada shell atau menu Chrome:
   ⋮ > Tambahkan ke layar utama / Install app

Setelah terpasang, ikon aplikasi muncul di launcher dan aplikasi berjalan dalam mode standalone. Tidak ada address bar Chrome pada mode standalone.

H. Ikon
Ikon bawaan dalam paket adalah ikon sementara. Ganti:
   icons/icon-192.png
   icons/icon-512.png
Dengan logo sekolah yang sudah dibuat dalam bentuk PNG persegi.
Setelah mengganti ikon, commit/upload perubahan ke GitHub Pages.

I. Perubahan aplikasi utama
Jika memperbaiki Code.gs/Index.html Apps Script:
1. Edit Apps Script.
2. Save.
3. Deploy > Manage deployments > Edit > New version > Deploy.
4. URL /exec tetap dapat dipakai oleh PWA selama deployment yang sama diperbarui.

J. Catatan offline
Service worker pada paket ini hanya membuat shell PWA dapat dimuat cepat. Data absensi, login, GPS, upload, dan PDF tetap membutuhkan koneksi karena backend tetap berada di Google Apps Script.

K. Troubleshooting
- PWA tidak menampilkan aplikasi: periksa appUrl di config.js.
- Instal tidak muncul: pastikan halaman dibuka dari HTTPS GitHub Pages, manifest dan ikon dapat diakses, dan buka ulang setelah service worker aktif.
- GPS tidak aktif: iframe sudah diberi allow="geolocation". Izinkan lokasi pada browser/HP.
- Tampilan tidak berubah: hard refresh atau hapus cache/service worker versi lama.
